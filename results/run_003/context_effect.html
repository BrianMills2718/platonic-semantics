What six words of context do to a shared semantic space

Every earlier result in this project showed the models bare single words. This is the same four systems, the same 212 concepts, asked again with each word sitting inside a sentence.

Drag the slider. Positions are fixed — they come from the combined agreement of both conditions, so nothing moves and you are watching only what changes. A concept is drawn as sharp as the four systems agree on its neighbours, and a link is brighter the more systems endorse it.

Watch the third number rather than the first. Context does not simply add agreement — it concentrates it. Total links actually fall, from 3,171 to 2,714, while the links every system endorses rise from 215 to 379. Weak, idiosyncratic connections are replaced by ones the models share.

And one relation became portable

The question this run was built to answer. Across runs 001 and 002 — every scale from 0.5B to 3B — no relation could be carried from one model to another at the level of a specific pair. Zero of ten, every time. That was the project's most stubborn negative result.

It was a fact about the stimulus, not about the models.

Relationbarewith contextp: bare → contextq

The honest size of this. HasProperty reaches q = 0.0500 — exactly on the correction threshold. One borderline result in ten tests is a lead, not a finding. What makes it worth reporting is that it was predicted in writing before the data existed, and that the three relations with any positive signal under bare words are the same three that improve under context, moving together.

IsA — the relation this project spent the most effort on — stays firmly negative under both. The ones that move are about properties and uses, not taxonomy.

Four systems: Qwen2.5-0.5B and XGLM-564M, English and Chinese. Six pairs. bloom_560m is excluded — it returns non-finite values on CPU and this run had to be CPU-only. Bare was re-extracted rather than reused from run 002, so the two conditions differ only in stimulus: same seed, split, layer selection, centring, device, precision and attention implementation.

Replication at 1.6B and 3B is extracting. One tier does not settle this. Figures from results/run_003/; method and limits in docs/RUN_003_RESULTS.md; the prediction is D20 in docs/DECISION_LOG.md, committed before extraction began.
